# Installation Guide:

1. Once you've downloaded the file, extract its contents using either the default Windows extractor or WIN-RAR, then click the extracted Void_Engine file.
2. Once you're inside of the Void_Engine file, click Mods.
3. Once you're in mods, take the VoidEngine.dll file and drag it into your Bonelab Mods folder.
4. Then, open the game and enjoy!

# Features:

- A complete physics overhaul with over 4 different presets. (Adaptive is preferable.)
- Custom finger physics.
- Custom UI changes.
- A feature called "Deadeye" which allows you to have lethal aim assist to the head when in slow motion. (Disableable within the "Advanced Settings" tab.)
- A spawn menu, avatar menu, and level menu searcher.
- An ammo display on your ammo belt.
- A desktop UI overlay showing NPC kills, Fusion player kills, and deaths. It is enabled by default and appears while Void Engine is enabled.
- A 30 second delayed despawn on uninteracted with dev weapons, which now includes the Dev Manipulator when using the Dev Tools radial menu shortcut.
- Functions in the MelonLogger which can be explained with the command: `function_help`, including `function_giveitem:` to search for and spawn items.
